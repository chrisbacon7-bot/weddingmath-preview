About this page and common questions

Which wedding budget tool to open

Start with the wedding cost calculator if you want the local total. Open the wedding budget calculator to split that total. Open the affordability tool if you know what you can save. Open cost per guest if you are deciding how many people to invite.

The Knot's 2026 Real Weddings Study (article updated July 28, 2026) puts the average at $34,200 for couples married in 2025, $292 a guest, with a median of $24,000. Zola's Wedding Cost Index (updated March 6, 2026) puts the average at $36,000.

Common questions

Which wedding budget tool should we use first?

If you know the place and the guest count, start with the wedding cost calculator. If you know what you can save, start with how much you can afford. The tracker is for quotes you have already received.

Are these wedding budget tools free?

Yes. They run in the browser. There is no account and no required email.

Every figure is cited on the sources page.
